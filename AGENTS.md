# service_starter

- Public, reusable C++20 library using only the standard library and Win32/POSIX.
- Keep application-specific code and private data out of this repository.
- Preserve lifecycle ordering, exception boundaries, Unicode paths and graceful shutdown.
- Build/test on Windows and Linux. Distinguish fake SCM/notify tests from actual service-manager integration.
- Track scope, progress and completion in this repository's GitHub Issues.
